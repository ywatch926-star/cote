HEISENBERG — OUT (manifestes caviar émis)
==========================================

Chaque vidéo analysée produit un `caviar_manifest_<stem>.json` ICI.

Contenu : verdict (OK / BLOCKED / REFUSED), Budget d'Attention (dépense /
respiration), propositions advisory (jump cuts, smash audio, punchline),
jamais de décision créative.

Le `*_pack_chunk.json` (émis via `--emit-pack-chunk`) est la part que
PERTURABO relit et intègre OPTIONNELLEMENT dans son pack (v1-compatible).

Manifestes et chunks émis peuvent être commités (JSON léger, traçabilité).
